ZikaMansle — Installation, étape par étape

1. Ouvrir config.js et remplacer COLLER_ICI_LA_CLE_sb_publishable par la clé PUBLIQUE Supabase commençant par sb_publishable_.
2. Déposer les quatre fichiers index.html, admin.html, config.js, programme-initial.js à la racine du dépôt GitHub zikamansle-programme (remplacer index.html existant).
3. Ouvrir https://zikamansle.github.io/zikamansle-programme/admin.html
4. Se connecter avec le compte admin créé dans Supabase.
5. Dans Initialisation, importer une seule fois les fiches initiales.
6. Dans Événements, modifier une fiche, ajouter l'URL Wix d'une photo, cocher Publié, enregistrer.
7. Consulter le programme public et actualiser la page.

Ne jamais intégrer la clé secret/service_role dans ces fichiers. Ne jamais y inscrire le mot de passe.
Les images sont saisies par URL Wix. L'upload direct depuis l'ordinateur n'est PAS encore implémenté.
La sécurité repose sur les politiques RLS existantes et l'authentification Supabase.
